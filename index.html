Autonomous operating model

Autonomy means deterministic delegation with preserved authority boundaries—not removal of human strategic control.

GitHub Actions

Rejects stale branches, verifies dependency contracts, scans security/hygiene, validates docs/disclosure, compiles, tests host isolation, runs Commander-boundary regression and full regression, builds curated distribution, and orchestrates the separately gated host-deploy workflow.

Sentinel runtime

Runs the canonical one-second monitoring loop, sensor normalization, contract/state evaluation, Incident management, diagnostics, evidence/report reconciliation, and bounded autonomous remediation already authorized by policy.

Commander

Retains strategic/final authority for architecture or contract amendments, privilege and production-scope expansion, provider activation, upgrade/rollback authority, and consequential exceptions.

AI / engineering assistants

May analyze, implement, test, and propose. They cannot manufacture authorization or convert an observed condition into production authority.

Runtime & automation specifications

Canonical runtime cycle

Canary → production probe → Gate 3 → bounded Gate 4 → TMUX sensor → normalization → contract verification → per-component state machine → Incident bridge → diagnostics → bounded report reconciliation.

CI hardening

Latest-main ancestry, dependency-version contract, disclosure/security scan, compile, explicit host-isolation contract, focused Commander-boundary regression, and full regression. Bounded engineering autonomy may operate these safe validation steps; production authority remains separately gated.

Evidence

Consequential success requires independent verification and durable evidence. Unknown or mismatched state fails closed.

Release / rollback

Readiness and artifact verification are evidence capabilities only. Upgrade/rollback execution remains unauthorized unless a separate contract and approval open that authority.

Installation

Standard installation keeps fail-closed defaults and does not auto-enable external delivery, live AI providers, or upgrade/rollback effects.

git clone https://github.com/arivonto/AIRIV-Sentinel-OSS.git "$HOME/airiv/airiv-sentinel"
cd "$HOME/airiv/airiv-sentinel"
python3.14 -m venv venv
venv/bin/python -m pip install --upgrade pip
venv/bin/python -m pip install -r requirements-dev.txt
PYTHONPATH=. venv/bin/python -m compileall -q sentinel tests
python scripts/validate_project_docs.py
PYTHONPATH=. venv/bin/python -m pytest -q -p no:cacheprovider
bash scripts/public_release_secret_scan.sh

Foreground runtime: PYTHONPATH=. venv/bin/python -m sentinel.
