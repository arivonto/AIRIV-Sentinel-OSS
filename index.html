Concept evolution

Sentinel has expanded through bounded, independently verified slices rather than unrestricted automation.

Foundation

24/7 systemd runtime, Incident lifecycle, deny-by-default remediation, exact execution, independent verification and execution replay identity.

Operational evidence

Durable incident reports, reconciliation, unattended rollups, Commander Attention Queue and disclosure-safe projection.

Commander delivery

Durable delivery identity, bound destination/transport continuity and deterministic non-network dry-run. External transport stays disabled.

AI execution

Single provider-neutral boundary, independent verifier, append-oriented evidence, durable replay identity and deterministic local no-network proof.

Runtime & evidence specifications

Runtime

  • Python 3.14
  • Linux + systemd
  • python -m sentinel
  • 1-second daemon cycle
  • 30-second health stale threshold
  • journal logging

AI identity

CLAIMED
→ RUNNING
→ SUCCEEDED / FAILED / UNKNOWN

Exact full-request SHA-256 continuity suppresses replay. Incomplete/ambiguous execution does not become automatic success or retry.

AI safe default

Provider adapter disabled, verifier deny-all, deterministic local proof disabled by default. Durable identity ledger excludes prompt/raw output/credentials/commands.

External effects

External Commander delivery and live AI-provider network access are disabled. Production-target expansion remains bounded and separately reviewed.

Installation

Installation preserves fail-closed defaults and does not activate external delivery, live AI providers or new production authority.

git clone https://github.com/arivonto/AIRIV-Sentinel-OSS.git "$HOME/airiv/airiv-sentinel"
cd "$HOME/airiv/airiv-sentinel"
python3.14 -m venv venv
venv/bin/python -m pip install --upgrade pip
venv/bin/python -m pip install -r requirements-dev.txt
PYTHONPATH=. venv/bin/python -m compileall -q sentinel tests
python scripts/validate_project_docs.py
PYTHONPATH=. venv/bin/python -m pytest -q -p no:cacheprovider
bash scripts/public_release_secret_scan.sh
